# Boru Hattı Analiz Paneli

Boru hattı sensörlerini simüle eden, uyarıları ve grafikleri gösteren bir izleme paneli.
HTML, Bootstrap, jQuery ve Chart.js ile yazıldı; sunucu gerektirmez.

## Çalıştırma

`index.html` dosyasını tarayıcıda açın.

### Yapay zeka asistanı (isteğe bağlı)

`scripts/config.example.js` dosyasını `scripts/config.js` olarak kopyalayıp
Gemini API anahtarınızı yazın. `config.js` depoya gönderilmez.

> Tarayıcıda çalışan bir anahtar, sayfayı açan herkes tarafından görülebilir.
> Herkese açık bir yerde yayınlayacaksanız istekleri kendi sunucunuz üzerinden yapın.
